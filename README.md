# DAB Microservices Project

## 📌 Description
This project is a simple microservices architecture built with ASP.NET Core.

## 🧱 Architecture
- DAB.Web → Frontend (MVC + Identity)
- DAB.API → Backend (Transactions microservice)

## 🚀 Features
- User authentication (login/register)
- Transaction management
- API communication using HttpClient

## ⚙️ Technologies
- ASP.NET Core
- Entity Framework Core
- SQL Server
